# أولاً: ردود واتساب السريعة (احفظها)

### 🔹 الرد الأول على أي طلب (خلال ٥ دقائق)
```
السلام عليكم [الاسم] 👋
تمام، وصل طلبك.

لأبدأ أحتاج منك ٣ أشياء فقط:
١) سيرتك الحالية (إن وجدت) أو بياناتك المهنية
٢) الوظيفة أو المجال المستهدف
٣) اللغة: عربية / إنجليزية / الاثنين

التسلسل:
📩 تستلم المسودة خلال ٤٨ ساعة
🔄 تعديلين مجانيين بعد التسليم
📄 تسليم PDF + Word

السعر: [الباقة] — [السعر] ر.س
أبدأ فور موافقتك.
```

### 🔹 سؤال السعر (مباشر وواضح)
```
أسعارنا 👇
📄 الأساسية — ١٥٠ ر.س
   سيرة (عربي أو إنجليزي) + تنسيق ATS + PDF/Word

💼 الاحترافية — ٢٥٠ ر.س  ⭐ الأكثر طلباً
   كل ما سبق + إعادة صياغة الإنجازات + رسالة تعريفية + تهيئة لينكدإن

✈️ الابتعاث — ٤٠٠ ر.س
   نسختان (عربي+إنجليزي) + رسالة دافع + مراجعة وثائق + استشارة ٢٠ دقيقة

⚡ عاجل ٢٤ ساعة: +٧٥ ر.س
كلها مع تعديلين مجانيين. أي باقة تريحك؟
```

### 🔹 يسأل «أقدر أسويها بنفسي؟»
```
تقدر، فعلاً 🙏
لكن الفرق عندي:
١) الصياغة تُكتب من واقعك أنت — مو قالب جاهز
٢) متوافقة مع أنظمة ATS اللي تفرز قبل الإنسان
٣) جاهزة خلال ٤٨ ساعة بدون رجوع وتطويف
٤) تعديلين مجانيين حتى ترتاح

أرسل سيرتك الحالية — أرسل لك تقييم مجاني خلال ساعة
بدون أي التزام.
```

### 🔹 يتردد / يسأل «وإذا ما عجبني؟»
```
عندك ضمانين:
🔄 تعديلين مجانيين بعد التسليم
💰 وإذا ما قتنعت بعد التعديلين → أُعيد لك كامل المبلغ

ومافي شي يبدأ قبل ما تتأكد من الخطة والسعر.
أرسل سيرتك وخلنا نبدأ 👇
```

# ثانياً: قوالب الشراكات (أولوية الأرباح)

> **القاعدة الذهبية:** لا ترسل إعلاناً. أرسل **قيمة أولاً، عرضاً ثانياً**.
> كل رسالة تبدأ بجملة مخصصة لهم — لا رسائل جماعية.

## 🎓 ١) جامعات / كليات / إدارة الإرشاد الوظيفي

```
السلام عليكم ورحمة الله،
أتابع بصفة دائمة [اسم الجامعة/الكلية] — خصوصاً [محدّد: مبادرة/قسم الإرشاد الوظيفي].

أقدّم خدمة متخصصة في كتابة السيرة الذاتية بالعربي والإنجليزي
متوافقة مع أنظمة الفرز الآلية ATS — بمعايير سوق العمل السعودي والخليجي.

اقتراحي لفائدة طلابكم:
📄 جلسة تقييم سير ذاتية (٤٥ دقيقة) مجاناً لدفعة متخرّجين
+ خصم خاص لطلابكم على الباقة الأساسية والاحترافية.

الفائدة: خريجون جاهزون وملفهم لا يُرفض آلياً قبل ما يصله إنسان.

تحب أرسل لك العرض التفصيلي والأسعار؟

مع خالص التحية،
[اسمك] — مسارك
```

## 🏕 ٢) معسكرات / bootcamps / برامج تدريب

```
السلام عليكم [الاسم]،
تابع محتوى [اسم المعسكر] — خصوصاً [مقطع/منشور محدّد].

فكرة مباشرة لفائدتكم قبل التخرج:
أفتح ساعتين أسبوعياً لمجموعة من متدرّبيكم لـ«تقييم مجاني لسيرتهم»
— يخرج كل طالب بتقرير مكتوب (٣ أخطاء + الحلول) خلال ساعة.

كمان أقدّم لخريجيكم خصم ٢٠٪،
وأعطي المعسكر عمولة ٢٠٪ على كل طلب يمرّ من رابطكم.

يعني: قيمة مجانية لطلابكم + دخل ل-program — بدون أي تكلفة عليكم.

مهتم؟ أرسل لك العرض الكامل.
```

## ✈️ ٣) صفحات ومبدئو الابتعاث (يوتيوب / تويتر / سناب)

```

وثائق التقديم على منصة «سفير».

اقتراح تعاون مفيد للطرفين:
📝 أجهّز مجاناً ٣ نماذج سير + رسالة دافع (بتوافق كامل) لجمهورك
   — تنشرها كقيمة إضافية لمشتركيك
🔗 مقابل رابط إحالة خاص بك يعطي متابعيك خصماً
💰 أو عمولة ٢٥٪ على كل طلب يمرّ عبر الرابط

الفائدة: محتوى مجاني مخصص + دخل إضافي لك.
أحب أعرف رأيك؟
```

## 📣 ٧) مجموعات واتساب / تيليجرام (بإذن المشرف أولاً!)

**أولاً اسأل المشرف — لا تنشر تلقائياً:**
```
السلام عليكم [اسم المشرف]،
أنا عضو في المجموعة وصاحب خدمة سيرة ذاتية للسوق السعودي.
تحب أشارك معلومة مفيدة (نصائح سيرة) وأذكر خدمتي مرة واحدة؟
أو أنشر محتوى قيّم أسبوعياً بدون إعلانات متكررة؟
بانتظار إذنك 🙏
```

**نصيحة محتوى داخل المجموعة (أقوى من الإعلان):**
```
📝 نصيحة اليوم: «مسؤول عن المبيعات» → «قاد فريق ٦ ورفع الإيراد ٣٢٪»
الفرق بينهم = مقابلة أو صفر مقابلة.
أي أحد يبغى يقيّم سيرته مجاناً يرسلي خاص 👍
```

# خامساً: أداة القياس — `?ref=`

| مصدر | الرابط |
