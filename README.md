# مسارك — صفحة خدمة السيرة الذاتية 📄

صفحة هبوط واحدة، عربية بالكامل، تحوّل الزائر إلى **طلب واتساب جاهز**.
لا قاعدة بيانات، لا لوحة تحكم، لا تسجيل دخول، لا اشتراك شهري — ملفات ثابتة فقط.

```
الزائر يملأ الاستمارة ← يُفتح واتساب برسالة جاهزة ← أنت تستلم الطلب وتنفّذه
```

---

## ⚡ التشغيل السريع

```bash
node serve.mjs        # ثم افتح http://localhost:4000
```

أو افتح `index.html` مباشرة في المتصفح — الموقع يعمل بدون أي خادم.

---

## ⚠️ غيّر هذه الأشياء قبل النشر

كلها في ملفين فقط: **`js/app.js`** و **`index.html`**.

| # | ماذا | أين | ملاحظة |
|---|------|-----|--------|
| 1 | **رقم واتساب** | `js/app.js` → `CONFIG.whatsapp` | صيغة دولية بدون `+` وبدون صفر يسار: `0501234567` ← `9665001234567` |
| 2 | **رابط الموقع** | `index.html` (canonical, og, twitter, JSON-LD) + `robots.txt` + `sitemap.xml` | منشور حالياً على `https://loorenzo220aa-bit.github.io/masarik/` — إن اشتريت نطاقاً خاصاً استبدل الرابط في الأماكن الثلاثة |
| 2ب | **البريد الإلكتروني** | `js/app.js` → `CONFIG.email` + `footer` في `index.html` | `alitaher2220@gmail.com` (تم الاستبدال) |
| 3 | **البريد والوقت والموقع** | `js/app.js` → `CONFIG.email` + قسم `footer` في `index.html` | بياناتك الحقيقية |
| 4 | **الأسعار والباقات** | `js/app.js` → `CONFIG.packages` و `CONFIG.addons` | تُحدَّث تلقائياً في البطاقات والقائمة المنسدلة |
| 5 | **التقييمات** | `js/app.js` → `CONFIG.reviews` ثم `showReviews: true` | التقييمات الحالية **ناصبة** — لا تفعّلها إلا بوضع تقييمات حقيقية من عملائك |
| 6 | **صورة المشاركة (og.jpg)** | `index.html` + ملف `og.jpg` | أعد توليدها بعد تغيير النطاق |

> 🔁 لتوليد صورة المشاركة من جديد: افتح `og.html` في المتصفح، عدّل النص إن أردت،
> ثم شغّل الرسم من الكونسول أو غيّر النص داخل `og.html` وأعد الالتقاط بدقة **1200×630**.

## 💬 كيف يعمل الطلب عبر واتساب

**الطريقة ١ — الأزرار العائمة والمباشرة**
كل عنصر عليه `data-wa` يفتح `wa.me` برسالة ترحيب جاهزة. أنواعها:

```html
<a data-wa="general">              ← رسالة ترحيب عامة
<a data-wa="pkg:الاحترافية">       ← رسالة تُذكر الباقة بالاسم
```

**الطريقة ٢ — الاستمارة**
`buildMessage()` في `js/app.js` يبني الرسالة من حقول المستخدم:

```
السلام عليكم 👋
أبغى أطلب خدمة سيرة ذاتية:

• الاسم: عبدالله السالم
• المجال / الوظيفة المستهدفة: محاسب
• مستوى الخبرة: خبرة ٣ إلى ٧ سنوات
• لغة السيرة: إنجليزية
• الباقة: الاحترافية
• الموعد المطلوب: عادي — خلال ٤٨ ساعة
• رقم التواصل: 05xxxxxxxx
• ملاحظات: أقدم على وظيفة في شركة أرامكو
```

لا يُرسل شيء تلقائياً — الزائر يراجع الرسالة ويضغط إرسال بنفسه.

## 📊 من أين جاء الزبون؟ (تتبّع مجاني)

أضف `?ref=` أو `?utm_source=` على أي رابط توزّعه، ويظهر المصدر داخل رسالة الطلب:

| الرابط | ما يظهر لك |
|--------|-----------|
| `site.com/?ref=snap` | `مصدر الطلب: snap` |
| `site.com/?utm_source=tiktok` | `مصدر الطلب: tiktok` |
| `site.com/?ref=car` | `مصدر الطلب: car` |

**استخدمه في:** قصص سناب شات، بايو تويتر/إكس، إعلانات، توقيع الواتساب، بطاقات العمل.
هكذا تعرف بالضبط أي قناة تجلب لك العملاء — بدون أي أداة مدفوعة.

## 🚀 النشر (مجاني بالكامل)

الموقع ملفات ثابتة — يعمل على أي استضافة. الأرخص: **مجاني**.

### الخيار أ — GitHub Pages (مجاني)
```bash
git init
git add -A
git commit -m "masarik landing page"
git branch -M main
git remote add origin https://github.com/USERNAME/masarik.git
git push -u origin main
```
ثم: **Settings → Pages → Deploy from branch → main → /(root)**.
رابطك: `https://USERNAME.github.io/masarik/`

> ⚠️ في GitHub Pages يُضاف مسار `masarik/` — لذلك اجعل الروابط في `index.html`
> **نسبية** (`css/style.css` كما هي) — وهي كذلك بالفعل ✓، وحدّث `canonical` و`og:url`
> و`sitemap.xml` بالرابط النهائي.

### الخيار ب — Netlify / Cloudflare Pages (مجاني)
ارفع المجلد بالسحب والإفلات أو اربط المستودع — يُنشر خلال ثوانٍ ويحصل على HTTPS تلقائياً.

### الخيار ج — استضافة مدفوعة
ارفع الملفات كما هي عبر FTP أو لوحة التحكم. لا يحتاج Node ولا PHP.

## 📈 بعد النشر — خطواتك التالية

1. **اجمع ٣-٥ طلبات فعلية** بأي وسيلة (أصحابك، تويتر، مجموعات) ونفّذها ممتازاً.
2. **اطلب تقييمات حقيقية** وضعها في `CONFIG.reviews` وفعّل `showReviews`.
3. **وزّع روابط بـ `?ref=`** على كل منصة تنشر فيها.
4. **أضف نماذج عمل** (قبل/بعد) حقيقية — أعلى عنصر إقناع في الصفحة.
5. ثم فكّر في الإعلان المدفوع: كل زيارة تكلّف، وكل طلب واتساب يقابله عمل مدفوع.

## 🔒 الخصوصية

- لا تُخزَّن أي بيانات على الموقع — لا قاعدة بيانات ولا كوكيز تتبّع.
- `localStorage`/`sessionStorage` غير مستخدمة إطلاقاً.
- البيانات تنتقل فقط عبر رسالة واتساب يكتبها الزائر بنفسه.
